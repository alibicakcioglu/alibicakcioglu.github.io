# Phone Selector

Answer a few questions about your preferences and get a phone suggestion. An early NMED 3203 exercise.

[Open it](https://alibicakcioglu.github.io/phone-selector/)

## How to use

Press **Start**, choose an answer to each question, and read the suggested phone. **Start Over** resets it.
